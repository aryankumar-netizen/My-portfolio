CASE STUDY 01 • PRODUCTION APP

VEBRA — Music & E-Commerce Web App

Full-stack music streaming and vinyl e-commerce web application featuring user authentication, dynamic artist/song database, shopping cart, and custom Admin Dashboard.

The Challenge: Designing a seamless platform integrating high-performance music streaming alongside vinyl record purchasing, role-based admin controls, and invoice generation.
The Architectural Solution: Engineered normalized 3NF MySQL relational schemas for songs, artists, orders & albums. CASE STUDY 02 • INTERACTIVE FRONTEND APPLICATION

FurEver Care — Pet Wellness & Veterinary Portal

Interactive pet care platform built with HTML5, CSS3, Vanilla JavaScript, and JSON data schemas featuring a Personalized Pet Owner Journey, Companion Health Journal with LocalStorage, Feeding Portion Calculator, and 24/7 Emergency Triage guide.

The Challenge: Pet parents frequently need emergency triage assessment in critical moments and an offline-first tool to track vaccinations and food diets without login hurdles.
The Architectural Solution: Engineered using modern Vanilla JavaScript, semantic HTML5, and responsive CSS3. Created an offline-first record persistence layer using browser LocalStorage and structured JSON schemas. Built an interactive portion calculator and an emergency triage decision tree.
HTML5 CSS3 Vanilla JS JSON Bootstrap 5 LocalStorage
